# 游玩体验逐项设置

建议按顺序做。人物、主线推进条件和结局不新增任务；环境观察仍然可选。

## 一 开场音量和操作说明

墓园 **001 OpeningController → 第 1 页**：

1. `RM_Act1_Cemetery` 的音量从 50 改为 **32**。雨声 35、雨天强度 2 可以先保留。
2. 开头“更改菜单访问”改为**禁止**；原有“更改保存访问：允许”保留。
3. 在最后开启 0001 的位置后插入“更改菜单访问：允许”，然后结束事件。
4. 将原操作说明替换为同一窗口内四行，脸图无、窗口背景、下方：

```text
\C[7]CONTROLS\C[0]
Arrow keys: Move
Enter / Space: Look or talk
Esc: Pause / save
```

这样过场不打开菜单，自由探索时可暂停和保存。原工程已经允许保存，不必再增加自动存档。

## 二 妈妈的长对话只说一次

墓园 **002 Mom → 第 1 页**：

1. 在原指令之前插入“条件分歧 / Conditional Branch”：独立开关 A 为 **OFF**，勾选“创建否则分支”。
2. 把原有的整段母女对话剪切到条件成立的分支内部，保留原等待和脸图。
3. 原对话末尾加“控制独立开关 / Control Self Switch：A = ON”。
4. 否则分支放一条“显示文字”：Mom 脸图索引 1，输入：

```text
\C[6]MOM\C[0]
I'll be right here.
```

5. 分支结束后没有其他指令。第 1 页不增加出现条件，不新建一个覆盖第 2 页的页面。

若你的 Mom 事件已经使用独立开关 A，请改用空闲的独立开关，并同步替换条件与设置。

## 三 修正妈妈探索提示

墓园 **002 Mom → 第 2 页**：保留出现条件 **0006 MomCall = ON**，自动执行。把右侧指令改为以下结构：

```text
条件：0002 VisitedGrave 为 OFF
  条件：0007 MomHintDelivered 为 OFF
    显示文字：RM_Face_Mom，索引 1，窗口，下方
      \C[6]MOM\C[0]
      Grandma's stone is near Dad.
      I'll be right here.
    控制开关：0007 = ON
  分歧结束
分歧结束
控制开关：0006 = OFF
```

**0006 OFF 要放在两个条件分歧外面**，否则自动执行可能一直重复。0007 用于保证这句提示只出现一次；0002 防止看完主墓碑后再被叫去看。

其他墓碑中现有的“独立开关 B、变量 0001 加一、达到四次开启 0006”的计数逻辑保留。它只触发提示，不是主线通关门槛。

## 四 两边的白花共享重复对白

墓园 **005 WhiteFlowers** 和 **018 WhiteFlowers** 都做同样处理：

1. 用“条件分歧：0008 FlowersSeen 为 OFF”包住原来的音效与完整对白，勾选否则分支。
2. 完整对白最后添加“0008 = ON”。
3. 否则分支放 Grace 脸图索引 7：

```text
\C[4]GRACE\C[0]
Flowers made her sneeze.
```

两个事件用的是同一个**普通开关 0008**，不是各自的独立开关。这样从墓碑左侧读过，右侧也会用短句。

## 五 两处小文字调整

只改“显示文字”内容，保留后面的计数逻辑。

| 事件 | 原文 | 替换后 |
|---|---|---|
| 017 OldGrave_4 | `It seems to be abondoned a long time ago.` | 两行：`It looks like no one has been here` / `for a long time.` |
| 019 OldGrave_2 | `The name on the grave is barely legible.` | `I can barely read the name.` |

前者修正拼写和语法，后者更接近孩子的具体观察。

## 六 可选体验插件

1. 将 `assets/js/plugins/RM_Act1_Experience.js` 复制到工程 `js/plugins`。
2. MV → 工具 / Tools → 插件管理器 / Plugin Manager（通常 F10）。双击空白行，名称选 `RM_Act1_Experience`，状态设 **ON**。
3. 放在 `Community_Basic` 后面。如果原 `RM_Act1_Polish` 已启用，将它设为 **OFF**，避免脚步声音叠加。原工程虽然存在这个文件，但本次提供的插件列表没有启用它。
4. 插件无必填参数。保存工程。

效果：面对可交互目标时出现低调英文提示；对话、过场和淡出时自动隐藏。每走两格才播一次轻脚步，过场强制移动不加脚步。暂停菜单只保留 Resume、Save、Options、Return to Title。Options 可关闭 Interaction Hints 或 Footsteps。

这是为当前第一幕地图 1、2 编写的插件。如果以后换地图编号或加入其他菜单插件，需要复查兼容性。不开启它，素材和事件修改仍能使用，只是没有提示、脚步及简化菜单。

## 保留的设计

墓园不开放冲刺，不加倒计时、任务箭头、收集评分或疾病知识弹窗。现有花朵、旧墓碑、亲属和盒子已经足够支撑短探索；本轮重点是减少重复等待和明确可互动对象。
