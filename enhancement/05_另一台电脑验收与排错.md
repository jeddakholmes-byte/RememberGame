# 另一台电脑验收与排错

以下由你在安装 RPG Maker MV 的电脑上操作。本包不要求在这台电脑运行游戏，也不需要运行 `tools` 中的脚本。

## 完成一项就勾一项

- [ ] 打开的是 `RememberMeAct1_Enhanced` 副本，原工程备份仍在。
- [ ] 三张脸图进入 `img/faces`，三张带 `$` 的行走图进入 `img/characters`。
- [ ] UncleJames 使用中年男性图，Aunt 使用棕发女性图，Grandpa 独立出现在 (16,7)。
- [ ] 三人的脸图没有错位、半张脸、相邻表情串格。
- [ ] 从 **New Game** 开始，开场结束后可以自由移动和按 Esc；剧情中不会突然打开菜单。
- [ ] Mom 的长对话第一次正常出现，再次交谈缩为一句。
- [ ] 未看主墓碑时调查其他四座墓碑，Mom 提示一次；看过主墓碑后，不再触发这句提示。
- [ ] 从左右两处调查花朵，第二次只有短句；主线不要求调查所有花或其他墓碑。
- [ ] 爸爸主线对话仍在调查主墓碑后解锁。
- [ ] 奶奶在门边拉门，爸爸走近后朝上，没有穿过奶奶或卡住。
- [ ] 奶奶叫 Grace 时 Grace 转头，爸爸喊完后有安静停顿，Grace 后退一步。
- [ ] 闪回结束恢复正常色调和雨声，没有心跳残留。
- [ ] 妈妈从下方走到父女身边，没有第二次黑屏传送到门口；盒子对白、图片和结束画面正常。
- [ ] 若启用体验插件，面对事件出现提示，读对白时消失；Options 可以关闭提示和脚步。
- [ ] 存档、读档和菜单的可见文字为英文。
- [ ] 新字体可见，带脸图的长句不出框；标题背景图片中的字保持原样。

## 常见问题

| 现象 | 检查位置与处理 |
|---|---|
| 角色变成一大片、只有半个人 | 文件名是否保留 `$`；是否误把脸图放进 characters；是否选择中间站立帧 |
| 新 PNG 不在选择列表 | 确认复制到当前打开工程，而不是另一份工程；关闭并重新打开编辑器 |
| 加了插件但没有效果 | 插件管理器是否 ON；仅复制 JS 文件不会自动启用 |
| 互动提示一直不显示 | 事件顶部 Note 是否有 RMHint；是否面对相邻事件；Options 中是否开启；对话或过场中本就隐藏 |
| 闪回停在移动阶段 | Grandma (12,5)、Dad (11,6) 是否正确；门边 (12,4) 是否可走；是否有新增事件挡住路线 |
| 爸爸走近后朝右 | 爸爸路线最后再加“朝上”，不要加额外移动 |
| Mom 一直自动说话 | 0006 OFF 是否在两层条件分歧之外；第 2 页是否仍以 0006 ON 为条件 |
| 妈妈走近被挡 | 玩家返回点应为 (13,7)；妈妈路线 (13,12) 至 (13,8) 不要放其他人物或阻挡 |
| 结束后又重复过场 | 010 第 3 页是否以 0005 ON 为条件且为空页；末尾是否设置了 0005 ON |
| 存档载入还是旧剧情 | 旧存档保存了开关、事件位置等状态；先用 New Game 确認新设置，不要只看旧存档 |
| 声音变得很密 | 旧 RM_Act1_Polish 是否仍 ON；不要与新脚步逻辑同时启用 |
| 字体报错或没变 | 按 04 的字体排错检查 CSS、TTF 路径、插件优先级与 FontFace 参数 |

## 建议的修改顺序

先完成人物素材并保存，再处理闪回，再做可选体验和字体。每一阶段在另一台电脑确认后另存一份备份，方便判断问题来自哪一步。

如果暂时没有时间做完所有细节，优先完成三件事：人物图像与爷爷、闪回后退与声音、字体插件。其余重复对白和提示可以稍后添加。
