Quick start

Play it

Click Play Act I. It runs in the browser exactly as it runs in RPG Maker MV — this is the original project, not a conversion.

Run it locally

Serve game/ over HTTP and open index.html. Opening the file directly will not work.

Edit it

Open game/Game.rpgproject in RPG Maker MV 1.6.1. Data lives in game/data/.
