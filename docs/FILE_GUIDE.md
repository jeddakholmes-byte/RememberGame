# File guide

Every file and folder in this repository, what it does, and whether you are allowed to touch it.

Legend for the **Edit?** column:

- **no** — engine file or generated by RPG Maker MV. Editing it breaks the project or gets overwritten.
- **careful** — you can edit it, but it is shared state; a mistake can stop the game from loading.
- **yes** — safe to edit, it is our own content.
- **new** — added for this repository, not part of the game.

## 3. `game/data/` — the game content

These 16 JSON files **are** the game. Maps, events and every line of dialogue live here. In the MV editor you never open them by hand — the editor reads and writes them. If you edit them outside the editor, keep the JSON valid and always work on a copy first.

| File | Size | What it holds | Notes |
|---|---|---|---|
| `MapInfos.json` | <1 KB | The map list: two entries, `Act1_Cemetery` (order 1) and `Act1_House_Flashback` (order 2). | Determines the order in the editor's map tree. |
| `Map001.json` | 51 KB | **Act1_Cemetery.** 24 × 18 tiles, parallax `!RM_Cemetery`, 20 events. The whole cemetery chapter. | The busiest file in the project. |
| `Map002.json` | 14 KB | **Act1_House_Flashback.** 24 × 18 tiles, parallax `!RM_House`, 3 events. The flashback and the ending. | The flashback is one long autorun event. |
| `System.json` | 6 KB | Global settings: game title (`RememberMe`), the 8 switch names, party members, the UI text in every menu, the title/menu operation sounds, `optDrawTitle: false`, `titleBgm`. | The single most dangerous file to hand-edit. It holds *everything* at once — language, volume, switch names, terms. |
| `Actors.json` | <1 KB | One actor: `Grace`, class 1, sprite `$RM_Grace`, face `RM_Face_Grace` frame 3. | |
| `Classes.json` | 14 KB | Grace's class and its level curve. Untouched default data. | RPG Maker fills this in; the game never levels up. |
| `CommonEvents.json` | <1 KB | Four empty common events. Nothing in the game calls them. | Can be ignored. |
| `Tilesets.json` | 17 KB | One tileset, `Act1_TransparentCollision`, built from `RM_Collision_A5` and `RM_Empty_B`. | Its note field reads: *"A5 tile 1 = walkable, tile 2 = blocked."* The art is a parallax, so this tileset exists only to draw the invisible collision layer. |
| `Animations.json` | 382 KB | The 117 stock battle animations. | None are used — the game has no combat. Kept because MV ships them. |
| `Enemies.json` | 2 KB | Four stock enemies (bat, slime, orc, minotaur). | Unused. |
| `Troops.json` | 1.5 KB | Four stock enemy groups. | Unused. |
| `Items.json` / `Weapons.json` / `Armors.json` | small | Stock item and equipment lists. | Unused. |
| `Skills.json` / `States.json` | 4–5 KB | Stock skills and states. | Unused. |

**Bottom line:** only `Map001.json`, `Map002.json`, `MapInfos.json`, `Actors.json`, `Tilesets.json` and `System.json` carry this game. The rest is the default MV database, kept so the project stays loadable.

## 4. `game/js/` — the engine

### 4.1 Core scripts (`game/js/`)

| File | What it is | Edit? |
|---|---|---|
| `rpg_core.js` | Graphics, input, audio, bitmaps, the scene manager. | no |
| `rpg_managers.js` | Data, config, storage, sound and battle managers. | no |
| `rpg_objects.js` | Game objects: party, map, player, events, the event interpreter. Most engine behaviour you would want to change is here. | no |
| `rpg_scenes.js` | Scene classes: title, map, menu, message, game over. | no |
| `rpg_sprites.js` | Sprite classes. | no |
| `rpg_windows.js` | Window classes: the message box, menus, the save screen. | no |
| `js/plugins.js` | The plugin switchboard. A list of `{name, status, parameters}`. **This is where plugins get turned on and off, and where you change their parameters.** | careful — but this is the intended place to work |
| `js/main.js` | Bootstraps everything and sets the canvas scaling. | no |

### 4.2 `game/js/libs/` — third-party libraries

`pixi.js` (4.5.4 WebGL renderer), `pixi-tilemap.js`, `pixi-picture.js`, `fpsmeter.js`, `lz-string.js` (save compression), `iphone-inline-video.browser.js`. Loaded in that order by `index.html`. Do not touch.

### 4.3 `game/js/plugins/` — plugins

Twelve files. Only the three marked **ON** are active; the rest sit in the folder unused.

| Plugin | Status | Purpose | Custom? |
|---|---|---|---|
| `Community_Basic.js` | **ON** | Official plugin. Sets `screenWidth: 816`, `screenHeight: 624`, cache limit 20, `alwaysDash: off`. **This is the only correct way to change the resolution — never edit `rpg_core.js`.** | no |
| `MadeWithMv.js` | **ON** | Shows the "Made with MV" splash before the title, with 120-frame fades and a 160-frame hold. | no |
| `RM_EnglishTypography.js` | **ON** | **Ours.** Forces the message window to use an English font independently of the project locale: `Arial, Helvetica, sans-serif`, size 26, outline 2. Written because a `locale: zh_CN` project otherwise selects a CJK font and renders Latin text badly. | **yes** |
| `RM_Act1_Experience.js` | **off** | **Ours.** The polish plugin: on-screen `Enter / Space: …` interaction hints driven by `<RMHint:>` event notes, quiet footstep SE while walking, and a cut-down menu (`Resume / Save / Options / Game End`). It is written and present but **not enabled in `plugins.js`**, and the maps carry no `<RMHint:>` notes yet, so enabling it alone does nothing visible except the menu and the footsteps. Installing it is part of the outstanding work. | **yes** |
| `RM_Act1_Polish.js` | **off** | **Ours, superseded.** An earlier version: title-BGM fallback plus footstep SE. `RM_Act1_Experience.js` replaces it. **Never enable both** — footsteps would play twice. | **yes** |
| `TitleCommandPosition.js` | off | Moves the title command window. | no |
| `AltMenuScreen.js` | off | Alternative menu layout. | no |
| `AltSaveScreen.js` | off | Alternative save/load layout. | no |
| `ItemBook.js` | off | Item compendium screen. | no |
| `EnemyBook.js` | off | Enemy compendium screen. | no |
| `WeaponSkill.js` | off | Per-weapon attack skill. | no |
| `SimpleMsgSideView.js` | off | Short skill names in side-view battle. | no |

> Plugin order matters. `Community_Basic` must come first so the screen size is set before anything measures it. Any new plugin loads from top to bottom.

## 5. `game/img/` — pictures

RPG Maker MV assets are all plain PNG on a fixed grid. **The most common way to break this project is to drop in a picture with the wrong dimensions.**

| Folder | Count | What it is | Custom files | Grid rule |
|---|---|---|---|---|
| `titles1/` | 21 | Title screen art. Only `RM_Title.png` is used (816 × 624). Note `optDrawTitle` is `false` in `System.json`, so the title screen is black and the art is drawn by the opening event instead. | `RM_Title.png` | 816 × 624 |
| `titles2/` | 2 | Title foreground overlays. Unused. | — | 816 × 624 |
| `parallaxes/` | 17 | The two background images that *are* the maps. | `!RM_Cemetery.png`, `!RM_House.png` | 1152 × 864, free-form; the `!` prefix means "do not tile" |
| `pictures/` | 2 | Full-screen images shown by the Show Picture command. | `RM_Gravestone.png` (the headstone close-up), `RM_Box.png` (the relic box) | 816 × 624 |
| `characters/` | 34 | Walk sprites. | `$RM_Grace`, `$RM_Aunt`, `$RM_Grandpa`, `$RM_UncleJames`, `RM_Family` | 144 × 192 for the four `$`-prefixed ones (3 columns × 4 rows of 48 × 48); `RM_Family.png` is 576 × 384 (3 × 4 of 192 × 96). **The `$` prefix means "one character, not eight". Removing it makes the sprite huge and wrong.** |
| `faces/` | 17 | Portrait sheets shown at the left of the message box. | `RM_Face_Grace`, `_Mom`, `_Dad`, `_Grandma`, `_Grandpa`, `_Aunt`, `_UncleJames` | 576 × 288 = 4 columns × 2 rows of 144 × 144, so 8 faces per sheet, **index 0–7**. Sheet `RM_Face_Grace` is 576×288 but sits inside the box at 144×144. |
| `system/` | 14 | The interface skin: `Window.png` (the 9-slice message/menu window), `IconSet.png`, `Balloon.png`, `ButtonSet.png`, `Loading.png`, `MadeWithMv.png`, `GameOver.png`, `Shadow1/2.png`, `Damage.png`, `States.png`, `Weapons1–3.png`. | none | Several have strict sizes; `Window.png` is 192 × 192 |
| `tilesets/` | 64 | Tile sheets. | `RM_Collision_A5.png` (384 × 768, holds the walkable/blocked markers), `RM_Empty_B.png` (768 × 768, deliberately blank) | 48 × 48 per tile; B–E sheets are 768 × 768 = 16 × 16 |
| `animations/` | 117 | Battle animation sheets. | none | Unused — no combat. 52 MB of the repo. |
| `battlebacks1/`, `battlebacks2/` | 50 each | Battle backgrounds. | none | Unused — 98 MB. |
| `enemies/`, `sv_enemies/`, `sv_actors/` | 70 / 70 / 20 | Enemy and battler art. | none | Unused. |

The tiles under `img/tilesets/*.txt` (31 small text files) are VX/MV tileset notes shipped by the RTP. Leave them alone.

## 6. `game/audio/` — music and sound

Two formats exist for every track: `.ogg` (used by desktop and Firefox/Chrome) and `.m4a` (needed by Safari and by iOS). **Both must stay.** Keep the folder flat — RPG Maker looks up audio by plain filename, with no subfolders.

| Folder | Count | What it is | Custom files |
|---|---|---|---|
| `bgm/` | 44 (22 tracks × 2 formats) | Background music. | `RM_Remember` (title), `RM_Act1_Cemetery`, `RM_Flashback`, `RM_Box` |
| `bgs/` | 24 | Background ambience. | `RM_Rain` (the cemetery), `RM_Room` (the flashback house) |
| `me/` | 36 | Short jingles. | none — stock |
| `se/` | 468 | Sound effects. | 16 originals: `RM_Confirm`, `RM_Chime`, `RM_Swell`, `RM_WindGust`, `RM_CrowCaw`, `RM_Step1–3`, `RM_Cloth`, `RM_DoorHandle`, `RM_DoorCreak`, `RM_Cardboard`, `RM_KnockHard`, `RM_DoorPalm`, `RM_Heartbeat` |

Note the asymmetry: `RM_Rain` is a **BGS** (looping ambience) and `RM_Room` likewise; the four `RM_*` in `bgm/` are music. Getting the folder wrong means the sound silently never plays.

`RM_Heartbeat` and `RM_KnockHard` are used only by the flashback. They are the two sounds the enhancement pass wants removed.

## 9. Things that are easy to get wrong

| Trap | Why it matters |
|---|---|
| Renaming a file under `img/` or `audio/` | Every reference lives in `data/*.json` as a bare string. Rename the file and the game silently shows nothing / plays nothing. |
| Removing the `$` from a character sprite | `$` means "this sheet holds one character". Without it MV reads a 3 × 4 grid of eight characters and renders a corner of the wrong one. |
| Removing the `!` from a parallax | `!` means "do not tile". Without it the background repeats. |
| Editing a map while a save exists | Old saves restore old switch states. **Always test from New Game.** |
| Adding a `README.md` inside `game/` | Fine for GitHub, but it will show up in the MV editor's project folder. Keep repo documentation in `docs/`. |
| Copying `patch_data/*` over `game/data/*` | It replaces the maps *and* the system settings wholesale. Only safe on a project that has not been touched since 2026-09-29. |
| Moving or renaming `game/` | It is the GitHub Pages entry point. The published URL would change. |
| Deleting `movies/` or `save/` | MV expects both to exist. |
| Deleting the unused RTP assets to shrink the repo | Tempting — 400 MB is mostly unused battle art and ambience. But they are the pooled library the MV editor offers in every dropdown, so removing them removes choices from whoever edits next. Trim only in a throwaway copy, never in this one. |
